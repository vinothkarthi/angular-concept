Angular decorator metadata

Class decorators tell Angular how a class participates in the application. Their metadata describes how Angular creates, uses, and connects that class.

@Component

Defines a component: a view (template) together with its behavior and dependencies.

selector
The element or attribute name used to place the component in a template.
template / templateUrl
Inline template markup or the path to an external template.
styles / styleUrl
Inline styles or the path to an external stylesheet.
imports
Standalone components, directives, pipes, and NgModules used by its template.
providers / viewProviders
Dependency injection providers available to the component and its view.
changeDetection, encapsulation, host
Configure change detection, style scoping, and host element bindings.
@Component({
  selector: 'app-profile',
  standalone: true,
  imports: [UserCardComponent],
  templateUrl: './profile.component.html',
  styleUrl: './profile.component.scss'
})
export class ProfileComponent {}

Standalone is the default in current Angular versions. Set standalone: false when declaring the component in an NgModule.

@Directive

Adds behavior to an existing element. It has no view of its own.

selector
CSS selector that identifies where Angular applies the directive.
inputs / outputs
Values accepted by the directive and events it emits to its host template.
host / hostDirectives
Host element bindings and behavior composed from other directives.
providers / exportAs
Providers for the directive and an optional template reference name.
@Directive({
  selector: '[appHighlight]',
  standalone: true,
  host: { '(mouseenter)': 'highlight()' }
})
export class HighlightDirective {}

@Pipe

Registers a class as a template pipe that transforms a value for display.

name
The name used in template expressions, such as value | titlecase.
pure
When true (the default), Angular calls the pipe when its input arguments change.
standalone
Whether it can be used directly by a standalone component (default: true).
@Pipe({
  name: 'shorten',
  standalone: true,
  pure: true
})
export class ShortenPipe {}

@Injectable

Marks a class as available for Angular dependency injection. Its providedIn option controls where Angular provides the service.

providedIn
Common values are 'root' for an application-wide singleton, 'platform' for a platform-wide instance, or a module/type for scoped provision. Use null when providing it explicitly. 
@Injectable({ providedIn: 'root' })
export class UserService {}

Provider recipes such as useClass, useValue, useFactory, and useExisting belong to provider configuration, not to @Injectable metadata.

@NgModule (legacy module-based applications)

Groups declarations, imports, providers, and exports for an NgModule-based application. Modern Angular applications commonly use standalone APIs.

declarations
Non-standalone components, directives, and pipes owned by this module.
imports
Other NgModules and standalone declarations this module uses.
exports
Declarations made available to modules that import this module.
providers
Dependency injection providers registered by the module.
bootstrap
Root component or components bootstrapped by the application module.
@NgModule({
  declarations: [LegacyPageComponent],
  imports: [CommonModule],
  exports: [LegacyPageComponent]
})
export class LegacyFeatureModule {}
